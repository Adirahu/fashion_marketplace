# VOGUEHUB Fashion Marketplace — First Version

A front-end fashion marketplace built with plain HTML, CSS and JavaScript.

## Run it

1. Keep the folder structure intact.
2. Open `index.html` in a browser.
3. No server or installation is required.

## Included

- Responsive fashion marketplace homepage
- Desktop sidebar + mobile navigation
- Search
- Category filters
- Clothing style filters for native, street, corporate, casual and occasion wear
- Product cards
- Nigerian fashion brand discovery cards
- Product detail modal
- Wishlist
- Shopping cart drawer
- Demo sign in / sign up
- Seller product upload
- Seller dashboard
- LocalStorage persistence

## Important

This is a front-end prototype. Authentication is simulated and passwords are NOT securely stored. Product uploads only exist in the current browser. Checkout is a demo.

For a production marketplace, connect:
- A real authentication service
- A database for brands/products/orders
- Cloud image storage
- A secure backend/API
- A payment gateway
- Seller verification and moderation
- Order tracking and notifications
